# Support

The skills in this repository are experimental and are **not covered by existing Splunk
support contracts**. They are not an official Splunk or Cisco deliverable — see
[DISCLAIMER.md](DISCLAIMER.md).

Splunk Support cases do not provide support for these skills. For help with supported
Splunk products, see
[Working with Splunk Support](https://www.splunk.com/en_us/resources/working-with-splunk-support.html).

## What you can do instead

| Situation | Where to go |
|---|---|
| A skill is wrong, out of date, or unclear | Open a GitHub issue, or a pull request — see [CONTRIBUTING.md](CONTRIBUTING.md) |
| A skill broke something in your environment | Open a GitHub issue so the skill can be corrected, and restore from your backup |
| You found a security vulnerability in a Splunk **product** | [Splunk Product Security](https://advisory.splunk.com/report) — not this repository |
| You found a security problem in this **repository** | See [SECURITY.md](SECURITY.md) |
| You need help with a supported Splunk product | Splunk Support, via your normal channel |

Issues and pull requests are answered on a best-effort basis, in personal time. There is
no response-time commitment.
